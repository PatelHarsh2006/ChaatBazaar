# Security Policy

## Supported Versions

The following table outlines which versions of this project are actively supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅                 |
| 5.0.x   | ❌                 |
| 4.0.x   | ✅                 |
| < 4.0   | ❌                 |

## Reporting a Vulnerability

We take security issues seriously and appreciate your efforts to responsibly disclose vulnerabilities.

- **Where to report:** Please submit security issues via [GitHub Security Advisories](https://github.com/PatelHarsh2006/ChaatBazaar/security) 
- **Response time:** You can expect an initial response within **72 hours**. We will provide regular updates (at least once per week) until the issue is resolved.
- **Process:**
  - After receiving your report, we will investigate and validate the vulnerability.
  - If accepted, we will work on a fix and coordinate a release.
  - If declined, we will explain why (e.g., not reproducible, out of scope).
- **Confidentiality:** Please do not disclose the vulnerability publicly until we have released a fix and confirmed resolution.

## Scope

- Supported versions listed above are eligible for security patches.
- Vulnerabilities in unsupported versions will not be addressed.
- Issues related to third-party dependencies should be reported upstream, though we will assist in coordinating if possible.

## Responsible Disclosure

We encourage responsible disclosure practices. Please:
- Provide clear steps to reproduce the issue.
- Include any relevant logs, screenshots, or proof-of-concept code.
- Allow us reasonable time to fix before public disclosure.

Thank you for helping keep **ChaatBazaar** secure!
